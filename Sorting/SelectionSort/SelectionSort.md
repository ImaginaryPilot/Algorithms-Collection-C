# Selection Sort

Selection sort is a **comparison** based sorting algorithm. It sorts by selecting the smallest element in the array and placing it to the front and keeps repeating the process.


### Dependencies

* GCC (The GNU Compiler Collection for C)

### Executing program

* Download file `SelectionSort.c` and `input.in` 
* Go to parent folder of these 2 files. 
``` 
gcc SelectionSort.c -o a.out
./a.out < input.in
```
