# Radix Sort

Radix sort is a linear sorting algorithm that considers the elements digit by digit (i.e. their significant values are sorted). Efficient for integers or strings with a fixed size.


### Dependencies

* GCC (The GNU Compiler Collection for C)

### Executing program

* Download file `RadixSort.c` and `input.in` 
* Go to parent folder of these 2 files. 
``` 
gcc RadixSort.c -o a.out
./a.out < input.in
```
