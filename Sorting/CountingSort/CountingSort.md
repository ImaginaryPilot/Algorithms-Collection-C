# Counting Sort

Counting sort is a **non-comparison** based sorting algorithm. It sorts by counting the frequency of each distinct element in the input array and use that information to place them in the correct order. 

### Dependencies

* GCC (The GNU Compiler Collection for C)

### Executing program

* Download file `CountingSort.c` and `input.in` 
* Go to parent folder of these 2 files. 
``` 
gcc CountingSort.c -o a.out
./a.out < input.in
```
