# Rod Cutting

Given a rod of n length and an array price, we must find the maximum value obtainable by cutting the rod into pieces and selling them for their corresponding prices.

### Dependencies

* GCC (The GNU Compiler Collection for C)

### Executing program

* Download file `Rod.c` and `input.in` 
* Go to parent folder of these 2 files. 
``` 
gcc Rod.c -o a.out
./a.out < input.in
```
