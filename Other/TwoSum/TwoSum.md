# Two Sum

Given an array and a target value, can you find 2 variables whose sum equate to the given target.

### Dependencies

* GCC (The GNU Compiler Collection for C)

### Executing program

* Download file `TwoSum.c` and `input.in` 
* Go to parent folder of these 2 files. 
``` 
gcc TwoSum.c -o a.out
./a.out < input.in
```
