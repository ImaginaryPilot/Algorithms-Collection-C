# Two Sum

Given an array and a target value, can you find 3 variables whose sum equate to the given target.

### Dependencies

* GCC (The GNU Compiler Collection for C)

### Executing program

* Download file `ThreeSum.c` and `input.in` 
* Go to parent folder of these 2 files. 
``` 
gcc ThreeSum.c -o a.out
./a.out < input.in
```
