# Insertion Sort

Insertion sort is a **comparison** based sorting algorithm. It sorts by splitting the array into 2 and each element on the right side will be placed in the correct order on the left side till the whole array is sorted.

### Dependencies

* GCC (The GNU Compiler Collection for C)

### Executing program

* Download file `InsertionSort.c` and `input.in` 
* Go to parent folder of these 2 files. 
``` 
gcc InsertionSort.c -o a.out
./a.out < input.in
```
